`two-colors.pes` was generated for these tests using pyembroidery 1.5.1.
The pattern has a red 40-by-40 square, then a blue crossed path with
long jumps to (-100,-80), (100,80), (-100,80), and (100,-80). It covers
signed short and long stitch displacements, jump flags, thread colors,
and color-change records in a complete PES container.
